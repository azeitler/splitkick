# Phone layout gap analysis (2026-10-16)

Desktop features that a phone (width < 768px, almost always Web Access in iOS
Safari) cannot reach or that break there. The audit was done by reading the code,
and nothing was run on a device. Items marked _unverified_ were inferred but not
traced end to end. See `mobile-layout.md` for how the phone layout works.

Reachable on the phone, no gap found:

- Worktree and project actions: new worktree and base session, project settings, GitHub issues, PRs, workflows, security, linked projects.
- Magic and git: commit, push, PR, review, merge, conflicts (`MobileToolbarMenu`). GitHub dashboard through the palette.
- Navigation: add project and Archived from Home, the palette with session search, unread on Home, Settings.
- Chat input: the model and backend sheet, the execution-mode dropdown.

Not audited: plan approval, AskUserQuestion, permission approvals, slash
commands, queued messages. A search for hover-only actions and `hidden md:`
wrappers in those components found nothing, but they were not read in full.
